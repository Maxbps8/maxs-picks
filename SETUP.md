## 1. Put the site on GitHub Pages (do this first)

A live URL makes later affiliate applications easier. Cost: $0.

1. Create a free [GitHub](https://github.com/signup) account if you do not have one.
2. Create a new public repository named **maxs-picks** (or `YOUR-USERNAME.github.io` if you want the site at the root of your GitHub Pages URL).
3. Set your git name and email, then push the contents of this folder (including `.nojekyll` and `index.html` at the root). Example, after you have created the empty repo:

   ```bash
   cd /workspace/plain-picks
   git remote add origin https://github.com/YOUR-USERNAME/maxs-picks.git
   git branch -M main
   git push -u origin main
   ```

4. In the repo: **Settings → Pages**. Source: Deploy from branch `main`, folder `/ (root)`.
5. Wait for the site. A project repo is usually `https://YOUR-USERNAME.github.io/maxs-picks/`. A user site (`YOUR-USERNAME.github.io`) is usually `https://YOUR-USERNAME.github.io/`. Links in this repo are relative, so either layout works.
6. You do not need Jekyll, npm, or any build tool. Do not buy a custom domain, theme, or ads to start.
7. Optional later: a free Substack for email. It can wait a week.
8. Have tax details ready for a **W-9**. Amazon, Impact, and some other programs will ask.
