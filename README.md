# Max’s Picks

A free, static affiliate site (plain HTML and CSS). No build step. Intended for GitHub Pages.

The working folder on this machine is `/workspace/plain-picks`. The suggested GitHub repository name is **maxs-picks**.

Nothing here has been published, pushed, or submitted to an affiliate program. See [SETUP.md](SETUP.md) for what Max needs to do, and [POSTING-CALENDAR.md](POSTING-CALENDAR.md) for the 10-week launch board and draft X posts for @Maxbps8.

## What’s in this folder

- `index.html` at the repo root, plus `.nojekyll` (plain HTML, not Jekyll)
- Shared styles in `css/styles.css`
- Sections: Sports, Tesla, Books, Dogs, Christian, Tools
- `about.html`, `disclosure.html`, `privacy.html`
- [SOURCES.md](SOURCES.md) records the official or retailer pages used in the articles

Product links are ordinary official or retailer pages until affiliate programs are approved. They are not raw placeholders and are not tracking links yet. Every article and the site footer carries an FTC-style disclosure. The Amazon Associates statement on the disclosure page is labeled as a placeholder until that account is approved.

## Suggested first read

1. Open `index.html` in a browser (featured: UK-led fan gear, the true crime list, and the Kentucky/Ohio Tesla winter kit).
2. Read [SETUP.md](SETUP.md).
3. When you are ready, create a GitHub repo named `maxs-picks` and push this folder’s contents. Do not add a custom domain or ads to start.
